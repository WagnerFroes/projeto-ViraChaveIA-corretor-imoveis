# ViraChave IA

Landing Page acadêmica da ViraChave IA, um SaaS de qualificação de leads imobiliários no WhatsApp.

## Publicação

O projeto é estático: basta publicar a raiz do repositório na Vercel. O arquivo `vercel.json` configura o cache dos assets.

## Estrutura

- `index.html`: Landing Page
- `assets/`: imagem WebP do Hero e JavaScript adiado
- `vercel.json`: cabeçalhos de cache para a publicação

Os PDFs e os arquivos-fonte das atividades acadêmicas ficam apenas em `entregas/`, fora do versionamento e do deploy público.
